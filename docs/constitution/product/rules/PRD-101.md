Engram's product scope MUST remain governed agent memory, source-grounded knowledge, derived belief and code intelligence, delivered by the Rust engine through SDK/MCP surfaces; vector search MUST remain a retrieval mechanism, not the product identity. Engram MUST NOT become an LLM host or application server/hosted control plane without an explicit scope decision.
