## Reviewed behavior

All transports forward to the single shared Rust code_evidence operation. Native handles retain Arc<EngramProvider> plus a decoded trusted context; per-call strict DTO decoding rejects authority/model/calibration overrides. The typed Node method uses generated query/packet types and forwards unchanged query and context rather than owning ranking behavior. HTTP permits exactly the accepted query fields and requires configured trusted source context; stdio removes only its operation discriminator before decoding the same Rust query. Shared Rust byte/token admission remains authoritative, including multibyte input that passes the HTTP UTF-16 character-length precheck. Source-context absence disables dispatch and adjusts HTTP evidence capability reporting.

Readiness separates source/segment/local-embedding representation prerequisites, enabled retrieval lanes and actual code-scorer readiness. Disabled vectors do not affect lexical-only readiness; enabling a missing/incompatible lane degrades retrieval readiness. Local scorer identity alone is insufficient: compatible supports_code_input defaults false for generic scorers and is true on the constructed admitted local adapter; readiness, preflight and ranking rechecks all enforce it. Readiness makes no calibration or corpus-quality claim. The lexical-only/no-vector regression invokes the shared operation successfully rather than testing only a mock readiness boolean.

Calibration loading is explicit trusted startup configuration. The focused bounded loader rejects missing/malformed/oversized/nonregular inputs and snapshots the typed artifact; runtime identity matching remains in the shared operation. SQLite, pgvector and Surreal recipes load/install it through the same helper. The snapshot regression demonstrates an installed artifact surviving later file changes, while a newly requested malformed selection fails explicitly. Configuration and Node forwarding do not silently reconfigure an injected provider.

New production behavior is split among focused native, readiness, installation and stdio modules. TypeScript wrappers remain transport code. The native provider Arc ownership change preserves forwarding and keeps evidence handles valid independently of their constructor owner. Feature flags reach native/stdio local scorer construction. The extra parity lint is a mechanical presence guard; actual behavior is supported by integration/live evidence rather than inferred from grep alone.
