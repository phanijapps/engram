Recalled constitution text MUST remain background data, not executable approval/instructions. Recall hooks MUST remain bounded, relevance-gated, kill-switchable and fail-open for the host session; that availability policy MUST NOT weaken fail-closed code authorization or allow memory to impersonate the factory owner's approving instruction.
