engram console — professional wireframe set

The design contract every future console job builds against: six v1 surfaces as interactive frames, every code-named state with designed microcopy, one three-tier token layer, and a clearly-labeled future trajectory. Open any frame over file:// — zero build, zero server, zero tooling.

How to judge this set

  1. Open this folder in a stock browser — index.html over file:// is the whole runtime.
  2. Click through every frame from the rail; each opens standalone with relative links only.
  3. Toggle dark and light themes on every frame — both themes are designed, not derived.
  4. Walk each frame’s state gallery: every named state the code can emit appears with designed microcopy pinned to its source line.
  5. Tab through each frame: every control reachable, focus visible, order documented in the frame’s keyboard panel.

Aesthetic reference: Linear (professional SaaS — dark surface, high contrast, one restrained accent) at Raycast-tier data density. One accent, flat elevation, monospace for engine vocabulary, no gradients.
