How to judge this set

  1. Open this folder in a stock browser — index.html over file:// is the whole runtime.
  2. Click through every frame from the rail; each opens standalone with relative links only.
  3. Toggle dark and light themes on every frame — both themes are designed, not derived.
  4. Walk each frame’s state gallery: every named state the code can emit appears with designed microcopy pinned to its source line.
  5. Tab through each frame: every control reachable, focus visible, order documented in the frame’s keyboard panel.

Aesthetic reference: Grafana / Linear / Datadog-class operations dashboard. Slate neutrals, one restrained blue accent reserved for state and action, quiet 1px borders, 2/4px radii, tabular numerals, uppercase micro-labels, no ornament.

Boot gallery — the states before there is anything to browse

The console names its own failure to start. Two boot states are required vocabulary (ui-not-built, port-in-use); three more are named in the code and designed here for completeness. Terminal states render as terminals — that is where you meet them.

port-in-use
● terminal — console start

engram-console: state: port-in-use — 127.0.0.1:7777 is already bound.
Stop the other listener or pass --port <N>.
exit code 4

Another console already holds the port — two consoles on one store would race, so this one refuses to start. Stop the other listener, or start this one on a different port. Diagnosed before the engine loads, so it never depends on native addons.

apps/console/server/main.mjs:130,175 · exit 4

ui-not-built

engram console

State: ui-not-built. Run pnpm --filter @engram/console build then restart. The JSON API is live at /api/health.

The UI bundle isn’t built yet — the server is fine. The API is already answering at /api/health; build the UI once and the console appears on the next start.

apps/console/server/app.mjs:374,405

store-absent
● terminal — console start

engram-console: state: store-absent — storage directory ‘~/.engram’ does not exist.
The console is read-only and never creates a store.
exit code 3

The configured path has no store. A read-only console that silently created one would be a write — so it names the state and stops. Pass the path of an existing store.

apps/console/server/main.mjs:150 · exit 3

origin-refused

Console requests must originate from a loopback host (127.0.0.1 / localhost / ::1).

This is the single-operator security model doing its job, not a malfunction. Reach the console from the same machine; remote origins are refused by design — with a named JSON state, never a silent hang.

apps/console/server/app.mjs:425-428

ui-read-error

A served UI file couldn’t be read mid-stream.

The server stays up and answers with this named JSON state instead of crashing — the stream’s own error handler catches what the pipe would have swallowed. Reload; if it persists, rebuild the UI bundle.

apps/console/server/app.mjs:411-418

Token layer — three tiers, one-way dependency

Every display value in this set resolves through tokens.css — a raw value outside the primitive tier is a defect the drift sweep can see (a grep for hex or rgb outside tokens.css must return nothing).

tier 1 · primitive Raw values, defined once, referenced only by semantics: the slate ink and paper ramps, one blue accent family, status hues, the 4px spacing grid in rem, the type scale, two quiet radii, shadows, z-index, motion. Names carry values, never meaning.
tier 2 · semantic Role assignments — surface, on-surface, outline, primary, focus, status roles, graph hues. Where theming lives: light values are the defaults, [data-theme="dark"] overrides them, and a prefers-color-scheme fallback stays in sync for attribute-less loads.
tier 3 · component Anatomy tokens scoped to a component class — --wf-btn-*, --wf-state-*, graph node fills — referencing semantics only, never primitives. wireframe.css consumes var(--*) exclusively.

Skills used and cited — what shaped what

All eleven UI skills were read and applied during authoring (job-013 REQ-008, MOS-002). Each citation names the concrete thing it shaped — not a hat-tip.

frontend-engineeringCreate-mode pre-flight and craft rules: named aesthetic reference (Linear at Raycast-tier density), the state-matrix discipline behind every frame’s state section, semantic-HTML rules (one main, one h1, labels on inputs, buttons for actions), and the no-AI-aesthetic rules — one accent, flat elevation, radius scale by element type, realistic content, no lorem ipsum.
archifyThe explorable standalone-HTML format these frames follow: self-contained, dark/light themed, conclusion-first, with no-JS explorable panels (native details/summary disclosures). The archify tool itself is diagram-scoped — the set takes the format, not the CLI.
component-contractEvery v1 frame’s contract panel: purpose, inputs, outputs with the emit-and-stop rule, slots, states owned, and an accessibility contract — designed before any future implementation, per the skill’s API-first principle.
token-architectureThe three-tier one-way chain in tokens.css, [data-theme] plus prefers-color-scheme kept in sync, minor-third spacing for data-dense surfaces, role-based token naming, and the audit grep that this job’s drift sweep (CHK-1) runs verbatim.
responsive-layoutGrid page structure with Flexbox inside cells, mobile-first min-width breakpoints in rem, auto-fill gallery and state grids, the table-to-labeled-blocks collapse under 48rem, clamp() fluid frame titles, and the no-JS rule — every layout behavior works without scripting.
ux-writingEvery state card’s copy: blame-free formula (what happened plainly + what to do next), empty states that orient and invite, no dead ends, engine-exact terminology — state names verbatim from code, human sentences around them.
a11y-engineeringThe keyboard contract table in every frame (key, action, focus destination, announcement), focus-visible paired with every hover rule, 24×24 minimum pointer targets, the polite live region on the binding line, the decorative-canvas decision for the graph, and the stated WCAG 2.2 AA gap below.
css-architecturewireframe.css structure: cascade layers declared once (reset, base, layout, components, utilities), class selectors only, specificity budget at two classes, no ID selectors, role-based class names that survive redesign.
fe-statusThe surface-state block below: future console jobs orient from one block — states covered, a11y status with the stated gap, known exceptions, next action — instead of re-deriving the set’s history.
rendering-strategyStatic-first decision for the set (SSG-equivalent file:// frames, zero hydration) and the islands rule the production console inherits: only genuinely interactive components ship script — in these frames, the theme toggle is the single JS island.
fe-performanceThe structural performance contract: system font stacks (zero webfont payload, no swap CLS), zero images (SVG and CSS only), skeletons that match final layout (no shift on load), one stylesheet pair per frame — LCP is the document, CLS is zero by construction.

Surface state — this set, honestly

states covered

ready, loading (skeleton), empty, partial (pagination), the six degraded api states, unbound, bound-fresh, bound-stale, canvas loading/unavailable, plus boot states ui-not-built, port-in-use, store-absent, origin-refused, ui-read-error. first-run is the empty store card; no-results, offline, and permission-denied have no v1 surface to own them (no filters, no network, no auth) — that absence is v1 scope, not omission.

a11y status

Built in: focus-visible on every control, tab order documented per frame, 24×24 targets, AA-contrast accent text in both themes (1.4.3, recomputed cycle 2 — evidence/build/wf-c2-contrast.log), live region on the binding line, decorative canvas with text equivalents. Owner-run at acceptance: the felt tab-through (AC-006 protocol). Stated WCAG 2.2 AA gap — not yet checked: 2.4.11 Focus Not Obscured, 2.5.7 Dragging Movements, 3.2.6 Consistent Help, 3.3.7 Redundant Entry, 3.3.8 Accessible Authentication.

performance

Untested by tooling at this tier (static files over file://; judgment is the owner dogfood). Structural contract: zero JS beyond the theme-toggle island, zero webfonts, zero images, skeletons that match final layout — documented so the production build inherits the argument, not just the pixels.

known exceptions

Representative fixtures, not exhaustive data (spec assumption); the professional-bar judgment lands late by design at owner acceptance (RISK-001); motion notes stay MAY-tier — the set animates only the skeleton pulse, guarded by prefers-reduced-motion.
