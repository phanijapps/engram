backend-unreachable

The configured backend is unreachable.

The engine behind the console didn’t answer. Check that the engine process is running and the backend setting matches it, then reload.

apps/console/server/app.mjs:88 · api.ts:24

store-invalid

The store directory does not hold a valid store.

The configured path isn’t an engram store. The console is read-only and never creates or repairs one — point it at the directory the engine created.

apps/console/server/app.mjs:91 · api.ts:25

configuration-invalid

The console configuration is invalid.

A setting failed validation before any read happened. Fix the flagged flag — backend or storage path — and restart the console.

Component contract — InventoryView inputs · outputs · slots · states · a11y — open to explore

Present every partition in the store as one selectable row with the engine’s own counts — the bounded summary over the whole store, never a record dump.
