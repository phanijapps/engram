Code candidates MUST be constrained by published-generation eligibility before they reach reranking/context composition; unavailable code authority MUST deny dependent code evidence while retaining independently authorized non-code results and reporting the source failure. Exact historical source reads MUST require their authorized lease, not another request's retained generation.
