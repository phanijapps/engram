`@engramlabs/mcp` releases MUST keep launcher/platform package versions and the binary's compiled `ENGRAM_BUILD_VERSION` in lockstep across linux-x64-gnu, linux-arm64-gnu, darwin-arm64 and win32-x64. One canonical executable per target MUST serve normal and runtime `--slim` modes, not resurrect full/slim artifact forks.
