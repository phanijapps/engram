Code reset MUST require preview→owner gate→apply/resume over an immutable hash-bound exact target journal; ambiguous ownership, substituted targets and changed preservation inventories MUST deny rather than expand to a scope wipe. Later lane failure MUST remain reported BestEffort recovery, not invented cross-store rollback.
