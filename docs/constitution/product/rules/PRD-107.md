A capability MUST NOT be called shipped merely because an adapter exists: it MUST be callable through the provider, N-API/TS and supported MCP surface or carry the root-required explicit exception, and `CapabilityReport` MUST describe the selected recipe's actual support. The launcher bundle's host limitations MUST be disclosed, not sold as uniform host behavior.
