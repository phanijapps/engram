Honesty contract, learned the hard way: the canvas caption always tells the truth about what is rendered — never a static list under an interactive caption. This wireframe is a static excerpt of the 14 most-connected entities; the shipped canvas loads react-force-graph-2d dynamically and renders all 31 with pan, zoom, and hover labels — and when the canvas cannot load, the bounded summary list renders under a caption that says exactly that.

State matrix — every named state, designed

The graph owns two orthogonal state axes — data (loading / empty / error) and canvas (loading / ready / unavailable) — every combination is designed and honestly captioned.
