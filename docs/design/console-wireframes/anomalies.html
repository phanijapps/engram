The minimal documented set: (1) the same subject value under multiple partitions of one tenant; (2) the same entity identity under multiple partitions. Anything outside this set is not a v1 anomaly — widening the set is a decision, not a drive-by. When duplication becomes actionable, the pruning-review frame (future) is where review work would live; nothing here links to a write.
