Consolidation MUST remain an explicit request→plan/run operation through injected mutation executors, not an incidental write side effect; only `dry_run == Some(false)` may apply. Gated mutation MUST keep pre/post evaluation and apply authorization visible and return task-level audit outcomes; the default allow-all apply gate MUST NOT be presented as host policy enforcement or a post-run regression as automatic rollback.
