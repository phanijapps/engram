# T7 independent implementation security review

**Verdict: Clean — ready to commit this T7 implementation after its construction gates pass.**

Scope: admitted asset manifests/runtime loading, explicit provisioning, offline BGE construction, local ONNX scorer and tokenizer, model-neutral scorer port, and provider/SQLite wiring. No held-out labels inspected.

## Resolved finding

**Medium — generic recall inherited code-specific admission limits.** Initial recipe wiring attached the bounded code scorer to generic unified recall, whose fused inputs can exceed the code pool/query/pair budgets; reranker errors would fail the generic request. This is resolved in `core/integration/src/sqlite/reranking.rs`: generic cross-encoder selection retains its existing RRF degradation behavior even with a code scorer present. The admitted scorer is constructed only for requested code cross-encoding and attached separately through `code_scorer`. A regression asserts the generic selector does not attach/invoke it.

The prior FIFO finding remains resolved: nonregular assets are rejected before open; opened descriptors are checked; Unix nonblocking/no-follow flags prevent FIFO stalls and final-component link substitution.

## Controls verified by inspection

- Model admission is compiled-in. Runtime loads confined, size/SHA-256-verified owned bytes through user-defined FastEmbed construction; there is no runtime HF download path. Both admitted models reject external-data dependencies rather than fetching undeclared files.
- Provisioning remains an explicit separate command, restricts initial/redirect URLs to HTTPS on fixed hosts (including the literal EU Xet bridge), and verifies bounded bytes before atomic file replacement.
- Scorer locality defaults false; exact tokenization/identity methods default unsupported. The actual adapter explicitly declares local execution. T8 must enforce this gate before handing source text to injected scorers.
- Query/document byte bounds and all pair token budgets are checked before the first model batch. Truncation is disabled; Jina padding uses its actual pad ID 1 and batch-longest padding. Scorer batches/candidate counts are bounded.
- Sorted model results are remapped by original index; missing/duplicate/out-of-range indices and nonfinite scores fail the whole result. No partial ranking is accepted.
- Actual weights/tokenizers/input and score contracts participate in recorded identities. Code passage identity binds the verified embedding asset identity.

## Evidence and limits

Reviewed the recorded actual Jina component artifact: correct deletion promotion, reversed-input alignment, a complete pair exceeding 512 tokens, and the recorded no-Internet-socket trace. This review did not rerun inference or independently recalculate trace/log hashes. Dependency/SAST scanner results are not established by this review.

T8 code invocation, authorization/preflight and degrade/error behavior; T9 transport parity; calibration/held-out quality; and retained-store rollout remain acceptance work. This verdict makes no beta or completed-feature claim.
