Release acceptance MUST exercise the actual packed launcher plus platform tarball in isolation, verify version and slim startup and validate the authored skill set/hygiene; testing the source checkout alone MUST NOT establish installed-bundle correctness. The bytes published MUST be the bytes whose acceptance was recorded.
