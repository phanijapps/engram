Beliefs MUST remain derived, revisable stances distinct from memory and source truth, with valid time separate from record time; contradiction records MUST remain reviewable signals, not silent truth overwrites. Hosts MUST NOT advertise record-time history or fuzzy belief recall where only valid-time/exact-subject lookup is implemented.
