Launcher skills MUST be generated by `prepack` from every authored `.agents/skills/*/SKILL.md` tree; generated `packages/launcher/skills` MUST NOT become an independent authoring source or ship Python cache files. Payload checks MUST distinguish “not generated” from verified byte parity.
