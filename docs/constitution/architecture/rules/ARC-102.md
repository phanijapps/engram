Engine operations MUST remain behind core ports in declared adapter/recipe zones. SQLite's existing `core/integration/src/sqlite/` zone MUST be identified as exempt composition, not evidence that neutral facade files may acquire SQL; a new engine MUST compose the same ports, not fork domain behavior.
