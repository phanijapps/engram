# Reference scope
ServiceNow before business rules can abort the current database action using current.setAbortAction(true). Error messages can use gs.addErrorMessage. The case uses these documented seams, not a full platform emulator. Its JSON configuration is synthetic offline context, not a deployable update set. Scope, rule execution order, actual persistence and effective access require instance evidence.

Sources: [Classic Business rules](https://www.servicenow.com/docs/r/api-reference/business-rules-classic/c_BusinessRules.html) and [Scripting messages](https://www.servicenow.com/docs/r/api-reference/scripts/r_ScriptingAlertInfoAndErrorMsgs.html), consulted 2026-11-15. No current release compatibility or live verification is claimed.
