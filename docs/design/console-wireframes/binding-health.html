State matrix — every named state, designed

The line owns six states: prompt, loading, bound-fresh, bound-stale, unbound, engine-error. Stale is informational; unbound shows the engine’s own words.

The repo id is an engine key, not a free-text search — the placeholder teaches the real shape (e.g. mem-alpha) and the last-used value is remembered for the next visit.
