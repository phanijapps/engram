## Findings

- **P1, resolved: code scorer admission could fail generic unified recall.** The first recipe wiring installed the bounded local scorer as the generic recall reranker. The composer deliberately sends the full fused candidate set before applying the request limit, whereas the code scorer rejects more than its configured maximum candidates, queries above its token bound, and long documents. Those errors would propagate from generic composition and fail the entire recall. The revised `core/integration/src/sqlite/reranking.rs` preserves the prior generic CrossEncoder selection behavior (warning plus `None`, hence existing RRF ordering), constructs the local scorer only for the code configuration with a ready embedder, and exposes it solely through the separate code scorer handle. The new panic-on-use stub regression checks that an available code scorer is not installed into generic recall. This minimal fix avoids importing code-specific bounds into the generic contract.

Installed source oracle: `/home/videogamer/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/fastembed-5.17.2/src/`. This is the installed version, with tokenizers 0.22.2 and ort/ort-sys 2.0.0-rc.12.

- `reranking/impl.rs` constructs user-defined rerankers directly from supplied ONNX bytes and tokenizer file bytes. Runtime construction takes this offline path rather than the HF constructor.
- `TextRerank` exposes its tokenizer. Its rerank implementation encodes query/document pairs with special tokens, batches with the tokenizer's padding, reads `logits[:, 0]` without a sigmoid transform, sorts by descending score, and preserves original input indices. The adapter correctly remaps by those indices, rejects missing/duplicate/out-of-range/nonfinite outputs, and never returns partial scores.

Jina's tokenizer configuration says 512 while the admitted model supports 8192, and its actual pad token ID is 1. The implementation correctly disables truncation after construction, sets pad ID 1 and BatchLongest, counts complete unpadded pairs with the same tokenizer, and validates all candidates before the first inference batch. Four pair special tokens are included. The configured 128-query/1024-pair defaults are admission limits, not silent truncation instructions.
- The BGE user-defined embedding path explicitly uses CLS pooling, no quantization, native 512-token window, and one CPU intra-op thread. FastEmbed's embedding output path supplies L2 normalization. It loads the admitted ONNX/tokenizer bytes rather than model aliases or opportunistic HF downloads.

## Construction, integrity, and error handling

- The neutral scorer port retains the previous adapter import path by re-export and adds compatible batch defaults. Unknown scorer implementations default to nonlocal, missing identity, and unsupported exact token inspection.
- Admitted manifests pin repositories, revisions, file byte lengths and SHA-256 values. The four JSON asset hashes for each model and the pinned BGE ONNX hash agree with the earlier independent source/metadata acquisition. Local read confinement, regular-file checks, bounded reads, exact digest verification, and owned verified bytes protect the runtime handoff. Declared external-data assets must exist in the manifest; both current models reject external-data usage rather than implicitly reading arbitrary side files.
- Provisioning is an explicit separate CLI. Downloads and redirects are restricted to admitted HTTPS hosts; source/destination confinement and per-asset temporary verified replacement reject oversized, truncated, corrupt, FIFO, and escaping-symlink inputs. Runtime inference performs no provisioning.
- Local inference failures and mutex/ORT errors are mapped to content-free provider errors. Sorted outputs are checked before rank trace mutation. Existing fusion trace, policy and provenance fields are preserved on successful reranking.
- The verified embedding manifest enters code passage representation identity, so changing actual admitted asset bytes changes representation identity independently of a configured model label.
