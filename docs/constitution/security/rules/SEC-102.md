Code register/bind/rebuild/inspect/reset MUST use the shared `CodeBindingAuthorizer`; recipe defaults MUST deny until a host explicitly supplies policy. A synthetic transport actor, repository path or caller branch MUST NOT create authority; `ScopeSetAuthorizer` MUST be described honestly as allowing every actor/repository inside its configured scopes.
