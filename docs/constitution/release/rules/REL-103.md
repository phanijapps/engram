An `@engramlabs/mcp` tag release MUST select a fresh immutable launcher/platform version from the exact `ci.yml`/`security.yml`-reviewed revision; partial npm publication MUST NOT be retried by moving that tag to different content. A `workflow_dispatch` dry run MUST NOT be described as publication.
