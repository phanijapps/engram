Accepted memory/retrieval/evaluation v1 changes MUST preserve field/enum meaning and optionality or introduce a new contract version; draft belief/hierarchy/consolidation extensions MUST NOT be advertised as frozen v1 commitments. Requiring branch binding MUST be disclosed as an activated breaking behavior change, not hidden behind additive payload fields.
