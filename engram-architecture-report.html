01What engram is

Engram is a storage-neutral memory + knowledge substrate for AI agents. It keeps memory (episodic observations), knowledge (source-grounded entities + graphs), beliefs (synthesized assertions over evidence), hierarchy (clustered navigation), and procedures (replayable runbooks) as distinct concepts in separate port crates. A single EngramProvider facade composes adapter cells into one fused-per-project workspace; the engram-mcp server exposes it to agents over JSON-RPC, and the on-top codegraph layer treats the codebase itself as a queryable graph.

Modularity rule: domain contracts come first, Rust owns deterministic behavior, TypeScript owns integration ergonomics, and infrastructure lives behind adapters. No god modules; crate roots are facades.

The first four stages are deterministic (the server, no LLM). The fifth is the agent's reasoning — the semantic doc↔code links that make the graph navigable by meaning, not just by exact name match.

08Invariants that must hold

  • Engine neutrality — engram-domain and core port crates never name an engine type or hold SQL. Enforced by lint.
  • Surface parity — a capability is not "shipped" until a Rust embedder AND a TS/N-API agent can both invoke it. Enforced by lint (20 capabilities, 0 debt).
  • No god modules — a file mixing construction, validation, state, orchestration, scoring, persistence, and error translation must be split before handoff.
  • Facades stay thin — crate roots are module declarations + narrow re-exports; behavior lives in focused modules.
  • Store adapters don't own composition — a backend recipe composes adapter cells; the adapter never crosses capability boundaries.
  • Distinct concepts — memory, knowledge, belief, hierarchy, policy, provenance, and evaluation stay separate unless an ADR changes the model.

09Self-hosting

Engram eats its own dog food: a project .mcp.json runs the locally-built engram-mcp against a single-file WAL store (./.engram/engram_data.db), which indexed the engram codebase itself. The engram-index, engram-find, and engram-distill skills drive the server; symbol_context, change_impact, graph_neighbors, and recall all answer against engram's own code.
