Consolidation tests MUST exercise the production provider wiring with `dry_run` true, absent and explicitly false, proving preview requests do not mutate; the gated-service fixture MUST prove a denied `ConsolidationApplyGate` never invokes its mutation executor. A preview label or isolated planner unit test MUST NOT substitute for these flow checks.
