Portable domain types/invariants MUST stay in `engram-domain`, conforming to the accepted model/contracts; memory, knowledge/ontology, belief, hierarchy, retrieval and consolidation MUST keep separate behavioral owners. New work MUST NOT recreate the retired `engram-core` facade as a canonical port owner or persist knowledge state inside the memory repository for convenience.
