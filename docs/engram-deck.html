Contract-First Agentic Memory

engram

Structured, durable recall for AI agents that need more than a context window. A Rust core that owns deterministic memory, knowledge-graph, belief, and retrieval behavior — with TypeScript bindings, 3D visualization, and a Postgres-ready backend.

02
Objective

Why engram exists

AI agents lose everything when the session ends. Vector databases return similar text without understanding why. LLM context windows forget. Engram is the layer where raw observations become durable beliefs, where retrieval is composed, and where policy, provenance, and scope govern every read and write.

🧠
Not a vector database
Vectors are one retrieval mode among six. The graph, the beliefs, the lifecycle — that's the product.
🔗
Not a knowledge store
Knowledge is source-grounded. Every fact traces to a chunk, every chunk to a document, every document to a source.
⚖️
Not a cache
Memory has a lifecycle: active → archived → redacted → forgotten. Redaction never leaks through retrieval.
03
Goals

What engram delivers

🎯 Durable Memory

Typed records with kind, scope, provenance, and policy on every write. Memory survives session boundaries. Forgetting is a domain concept (delete/redact/tombstone/archive), not a DB delete.

🔍 Composed Retrieval

Six modes fused via Reciprocal Rank Fusion: temporal, cue, hierarchical, semantic (vector), graph, and keyword (BM25). Never single-mode. Full FusionTrace for explainability.

🧬 Belief Synthesis

Derived, recomputable stances over evidence — bi-temporal (valid_from/until ≠ recorded_at). Contradictions are reviewable signals, never automatic truth changes.

🛡️ Governed Access

Policy, provenance, and scope are required fields checked at runtime on write, retrieve, ingest, consolidate, and forget. Redacted records cannot leak through any path.

🏗️ Engine-Neutral

Contract-first domain types outrank SQL. Swap SQLite → Postgres → SurrealDB by config string. An engine-neutrality lint enforces it.

📊 Self-Improving

The code-intel tools index engram's own codebase, find bugs in themselves, and the fixes become the next improvement. The dogfood loop.

Conceptual Architecture

Eight domain concepts

Each is a distinct axis with its own port, lifecycle, and contract.

📦
Memory
Typed records with lifecycle: active → archived → redacted → forgotten. Append-only events.
🕸️
Knowledge Graph
Source → Document → Chunk → Entity → Relationship. Every fact traces to a source.
💡
Beliefs
Bi-temporal derived stances. Recomputable. Contradictions are reviewable signals.
🌳
Hierarchy
Louvain communities + aggregate layers for context compression. Navigation ≠ storage.
🔀
Retrieval
Six modes fused (RRF) + cross-encoder rerank → ContextPayload with FusionTrace.
♻️
Consolidation
Reflection (memories → beliefs) + decay (Ebbinghaus). Explicit, auditable pipeline.
🛡️
Governance
Policy + provenance + scope on every record. Checked at runtime on every path.
📜
Contracts
Domain types outrank SQL. TypeScript generated from Rust. Portable across engines.

Technical Architecture

How it's built

Rust Core (15 crates)

  • ▸engram-domain — portable types, invariants, serde. No SQL, no engine names.
  • ▸engram-retrieval — RRF fusion, reranker port, FusionTrace, VectorIndex port
  • ▸engram-code — tree-sitter parsing for 13 languages, cross-file resolution, framework patterns
  • ▸engram-graph-analytics — PageRank, betweenness, Louvain (std-only, zero deps)
  • ▸engram-integration — EngramProvider facade, engine-neutrality enforced by lint

TypeScript Layer

  • ▸@engram/node — N-API binding over the full Rust facade (transport, not implementation)
  • ▸@engram/client — ergonomic application SDK
  • ▸@engram/runtime — CLI wrappers, MCP HTTP server, LLM provider abstraction
  • ▸engram-cc — React + three.js 3D knowledge graph explorer
  • ▸Generated contracts — TypeScript types from Rust, never hand-written

Enhancing AI Agents

Memory that makes agents smarter

Agent observes
→
engram writes memory
→
consolidation reflects
→
beliefs synthesized
→
agent recalls fused context
🧠
Persistent Recall
Memories written in session 1 are retrievable in session 100. The agent remembers decisions, constraints, stakeholder preferences — without re-reading its entire history every turn.
🎯
Grounded Answers
Every recall result carries provenance: which chunk, which source, which git revision. Agents cite their sources. Hallucinated "facts" can't masquerade as grounded knowledge.
🛡️
Governed Access
Policy checks on every path: scope isolation, retention, sensitivity, allowed-uses. Redacted memories don't leak through retrieval, links, or explanations. Multi-tenant by design.
💡
Belief Lifecycle
Agents form beliefs from evidence, mark them stale when sources change, retract when invalidated. "True as of T" retrieval — the whitespace no competitor owns.
🔄
Self-Improvement
Agents store their own findings, learnings, and gotchas in engram. The next session starts from accumulated context, not from zero. The dogfood loop: tools → find bugs in tools → fix tools → better tools.
🤖
Agentic R&D
The Ask pattern: an LLM autonomously calls recall, list_memories, graph_overview to answer questions — the agent orchestrates its own tool calls with full trace visibility.
