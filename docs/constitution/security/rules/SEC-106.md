Agent-bundle install/remove MUST touch only Engram-owned name-tagged entries, protect authored source trees and refuse symlinked destination components; a same-named foreign skill/agent MUST NOT be overwritten or removed. Packaged skills MUST NOT smuggle symlinks into a host's executable agent context.
